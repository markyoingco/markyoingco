Recent Computer Science graduate from Marquette University and originally from the Chicago area. I build full-stack applications, developer tools, data-oriented systems, AI-enabled software, and practical technical solutions.

I built a multi-mode portfolio platform with three connected experiences: a cinematic **Webpage**, an interactive command-line **Terminal**, and **MarkAI**, a conversational portfolio assistant. The experience opens with a custom ASCII-inspired entry and transitions into an interactive celestial mode selector featuring a detailed Moon in Dark Mode and a rotating Earth in Light Mode with interactive travel-location pins.
