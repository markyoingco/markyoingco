# Mark Yoingco

Recent Computer Science graduate from Marquette University and originally from the Chicago area. I build full-stack applications, developer tools, data-oriented systems, AI-enabled software, and practical technical solutions.

I built a multi-mode portfolio platform with three connected experiences: a cinematic Webpage, an interactive command-line Terminal, and MarkAI, a conversational portfolio assistant. The experience opens with a custom ASCII-inspired cinematic entry and transitions into an interactive celestial mode selector featuring a detailed Moon in Dark Mode and a rotating Earth in Light Mode with location-based travel pins.

MarkAI uses a React/Vite interface, private PHP backend, Cloudflare Workers AI, approved public knowledge, intent classification, typo-tolerant routing, contextual follow-ups, response validation, deterministic fallbacks, privacy safeguards, anonymous usage limits, and regression testing.

I have also contributed to senior design projects, robotics software, systems programming, Unity applications, and data projects. I am currently seeking entry-level opportunities in software development, full-stack applications, developer tools, data-oriented systems, technical support, and related technology roles.
